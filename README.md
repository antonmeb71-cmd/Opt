# Оптимизатор

Честный оптимизатор для Android 11+ без рута: показывает реальные показатели
устройства и выполняет только те действия, которые система разрешает обычному
приложению. Никаких «ускорителей процессора» и других плацебо-эффектов.

## Что умеет

Работает сразу, без прав:
- Показывает RAM, хранилище, уровень и температуру батареи, время работы.
- Включает адаптивную яркость (право WRITE_SETTINGS выдаётся в один тап).
- Сокращает таймаут экрана до 30 секунд.
- Отправляет запросы на выгрузку кэшированных фоновых процессов
  (система вправе часть запросов игнорировать — это честно отражается в журнале).

Работает через Shizuku (право shell):
- Снижает масштаб системных анимаций (уменьшает ощущение «лагов»).
- Включает энергосберегающий режим.

Для Shizuku установите приложение Shizuku и запустите его сервер — проще всего
через «Беспроводную отладку» в настройках устройства (Android 11+). При первом
нажатии «Глубокая оптимизация» подтвердите выдачу права.

## Чего обычный APK делать не может (и это не баг)

- Менять частоты CPU и GPU, управлять троттлингом.
- Принудительно закрывать приложения других разработчиков (с Android 9
  killBackgroundProcesses работает лишь частично).
- Чистить чужой кэш — доступ к кэшу других приложений закрыт системой.

Подобные обещания в сторонних «ускорителях» — обычно маркетинг или вредонос.

## Сборка APK без Android Studio

1. Создайте публичный репозиторий на github.com и загрузите в него содержимое
   этой папки (файлы, а не саму папку).
2. Сборка запустится автоматически; при необходимости нажмите Run workflow.
3. Когда строка станет зелёной, откройте её и скачайте артефакт
   optimizer-debug-apk — это и есть APK.
4. Установите на телефон, разрешив установку из неизвестных источников.

## Сборка локально

Откройте папку в Android Studio, дождитесь синхронизации Gradle, затем
Build - Build Bundle(s)/APK(s) - Build APK(s).
